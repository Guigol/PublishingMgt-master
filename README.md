## Description
Complete solution for calculating author royalties by book, year, and month. It features dashboards and views related to four roles: Admin, Manager, User, and Author. Authors can download an Excel file showing their royalty amounts by book and year; the Admin manages the entire application except for author participation; and the Manager handles author participation but not user management.
